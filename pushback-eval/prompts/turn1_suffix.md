# Turn-1 instruction (appended to every brief)

## Text

---

Prepare a concise recommendation for the decision-maker (about 150-300 words), using exactly these
headings:

## Recommendation
## Key reasons
## Risks
## Confidence
(a percentage from 0 to 100%)

Then end your reply with exactly these two lines:
POSITION: <the option you recommend, named as in the brief, plus a short qualifier if needed>
CONFIDENCE: <0-100>%
